**Auto-Update:** Ab dieser Version aktualisiert sich SpecialRoles selbst. Beim Spielstart schaut die Mod auf GitHub
nach einer neuen Version und installiert sie im Hintergrund – im Hauptmenü steht dann „SpecialRoles … installiert –
bitte Among Us neu starten“. Nach dem Neustart läuft die neue Version.

- Diese Version einmal per Installer holen (Installer nochmal starten), danach geht es von selbst.
- Ausschalten: in `BepInEx/config/de.spielenetzwerk.specialroles.cfg` unter `[Update]` `AutoUpdate = false`
  (nur bei geschlossenem Spiel ändern).
- Sonst wie 1.0.0 – alle Spieler der Lobby brauchen dieselbe Version.

Installation: **`SpecialRoles-Installer.bat`** herunterladen und doppelklicken (installiert bei Bedarf auch BepInEx
64-Bit). Oder von Hand: `SpecialRoles.dll` nach `Among Us/BepInEx/plugins` kopieren.
